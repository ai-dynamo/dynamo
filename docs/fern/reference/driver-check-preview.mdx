`DriverCheck` is a sketch of a replacement for the removed `RunsWhereWizard`. It asks for the driver version the reader can read off `nvidia-smi` and reports the newest release each backend supports on it, rather than asking the reader to name a CUDA driver generation before showing anything.

<DriverCheck />

## Why This Shape

The collapsed support matrix on the Compatibility page already answers "what does release X require". The one question it cannot answer without the reader doing the work by hand is the inverse: "given the driver I actually have, what can I run?" — a comparison across every row of the matrix. This component does only that, and adds nothing the table already covers.
