[NeMo RL](https://github.com/NVIDIA-NeMo/RL) is a post-training library that uses Megatron Core or Automodel for training and vLLM or SGLang for inference, with Ray to coordinate them. The Dynamo integration is a NeMo RL setting, `policy.generation.dynamo: true`, that lets Dynamo handle the inference and rollouts: NeMo RL starts a Dynamo frontend inside its own Ray job, and NeMo RL's vLLM engines register with it.

## Tutorial: Train Qwen2.5-1.5B with NeMo RL + Dynamo

This tutorial covers how to train Qwen2.5-1.5B to solve math problems through reinforcement learning on the OpenMathInstruct-2 dataset using the GRPO algorithm. The RL loop runs on NeMo RL through KubeRay, and Megatron Core trains the model on one GPU. NeMo RL usually sends rollout requests to its vLLM engines directly. With `dynamo: true`, it starts etcd, NATS, and a Dynamo frontend inside the same job instead, and its two vLLM engines register with the frontend, so every rollout request goes through Dynamo's KV-aware router. No DynamoGraphDeployment is involved.
