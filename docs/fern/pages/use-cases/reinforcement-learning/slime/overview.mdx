[Slime](https://github.com/THUDM/slime) is a reinforcement learning framework that uses Megatron-LM for training and SGLang for inference through KubeRay. The Dynamo integration with Slime lets Dynamo handle the inference and rollouts, which is served through a DynamoGraphDeployment.

## Tutorial: Train Qwen3-0.6B with Slime + Dynamo

This tutorial covers how to use the Dynamo integration with Slime to train Qwen3-0.6B to solve elementary math problems through reinforcement learning on the GSM8K (Grade School Math 8K) dataset using the GRPO algorithm.

</CardGroup>
