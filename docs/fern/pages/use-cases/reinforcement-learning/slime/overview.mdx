[Slime](https://github.com/THUDM/slime) trains with Megatron-LM on KubeRay while Dynamo serves the SGLang engines that generate its rollouts.

## Tutorial: Train Qwen3-0.6B with Slime + Dynamo

This tutorial covers how to train Qwen3-0.6B to solve elementary math problems through reinforcement learning on the GSM8K (Grade School Math 8K) dataset using the GRPO algorithm. The RL loop will run on Slime through KubeRay using Megatron-LM. This differs from the typical Slime use case in that instead of serving inference through Ray, the Dynamo operator is brought in so that the model and rollout can be deployed through DGD.

<Note>
Although Slime doesn't require Kubernetes, this tutorial covers the Kubernetes use case because the Dynamo operator requires it.
</Note>
