Release notes for Dynamo v1.0.0 and newer are mirrored here from the [GitHub releases](https://github.com/ai-dynamo/dynamo/releases), with breaking changes tracked on the [Deprecations](deprecations.mdx) ledger and known issues on the [Known Issues](known-issues.mdx) page. Patch releases are folded into their base release's page. Earlier releases link to GitHub.

<Note>
For the artifact inventory each release shipped — container images, wheels, Helm charts, crates — see [Release Artifacts](../release-artifacts.mdx).
</Note>
