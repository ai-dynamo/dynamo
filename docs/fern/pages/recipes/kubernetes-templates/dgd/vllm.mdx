title: vLLM Deployment Templates

---

Copy-paste deployment templates for the vLLM backend, grouped by topology and feature. Each template
includes a `DynamoGraphDeployment` that uses `nvidia.com/v1beta1`; some templates also include or
require related Kubernetes resources. The manifests are embedded from
[`examples/backends/vllm/deploy/`](https://github.com/ai-dynamo/dynamo/tree/main/examples/backends/vllm/deploy).
Set the image tags, secrets, storage, and hardware-specific fields required by your environment before
applying a template.

Apply a template with:

```bash
kubectl apply -f agg.yaml
```

<Note>
Apply every document in a multi-resource file. For templates with separate supporting files, apply or
install those resources as described in the corresponding accordion.
</Note>
