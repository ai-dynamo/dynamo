Model sizes are approximate checkpoint weights in decimal GB, including text encoders, VAE, or

and backend loading choices change the runtime footprint. Duplicate single-file exports are excluded.

## Other Existing Examples

Additional local launch scripts and FastVideo deployments are available on the same topic pages.

| Case | Backend | Model | Available Examples |
|------|---------|-------|--------------------|
| Text-to-video | FastVideo | `FastVideo/FastWan2.1-T2V-1.3B-Diffusers` | [Local script and two existing DGDs](fastvideo.mdx); experimental custom worker |
| Text-to-video | SGLang | `Wan-AI/Wan2.1-T2V-1.3B-Diffusers` or `Wan-AI/Wan2.1-T2V-14B-Diffusers` | [Video Generation](video-generation.mdx): `text-to-video-diffusion.sh`; local only |
| Text-to-video | TensorRT-LLM | `Wan-AI/Wan2.1-T2V-1.3B-Diffusers` | [Video Generation](video-generation.mdx): `agg_video_diffusion.sh`; local only |
| Two-stage image generation | vLLM-Omni | `zai-org/GLM-Image` | [Image Generation](image-generation.mdx): `disagg_omni_glm_image.sh`; local only |
| Cross-node image generation with NIXL | vLLM-Omni | `zai-org/GLM-Image` | [Image Generation](image-generation.mdx): `disagg_omni_glm_image_nixl.sh`; local only |

The SGLang `image_diffusion.sh` defaults to `black-forest-labs/FLUX.1-dev`; the image DGD
above instead uses `black-forest-labs/FLUX.1-schnell`. A shared workload does not imply identical
model defaults or runtime requirements.

Realtime speech and transcription remain under [Audio and Realtime Serving](audio.mdx).
The CPU-only sample diffusion backend (`agg_diffusion.sh`) remains under
[Custom Backends and Testing](custom-backends.mdx); it does not load a real model.
