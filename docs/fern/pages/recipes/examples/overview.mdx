The Dynamo repository ships runnable examples for every supported backend and many
Dynamo features. Use this page to find the one that matches your environment and
goal, then follow its canonical guide. The source under [`examples/`](https://github.com/ai-dynamo/dynamo/tree/main/examples)
tracks `main`; if you run a stable release, check out the matching release branch
before using a script. Model recipes live under [Model Recipes](../model-recipes/overview.mdx);
this page covers the broader example tree.

## Getting started

| Example | Use it when | Source |
| --- | --- | --- |
| Hello World custom backend | You want the smallest Dynamo runtime service (endpoint, worker, streaming) and no GPU. | [`examples/custom_backend/hello_world`](https://github.com/ai-dynamo/dynamo/tree/main/examples/custom_backend/hello_world) |
| Request cancellation demo | You need to cancel in-flight requests across a client, a proxy, and a backend. | [`examples/custom_backend/cancellation`](https://github.com/ai-dynamo/dynamo/tree/main/examples/custom_backend/cancellation) |
| Chat templates | A model's Hugging Face chat template lacks the parser markers Dynamo needs; use a vendored template instead. | [`examples/chat_templates`](https://github.com/ai-dynamo/dynamo/tree/main/examples/chat_templates) |
