These examples demonstrate different runtime and testing workflows; they are not interchangeable inference backends. Follow the [Hello World README](https://github.com/ai-dynamo/dynamo/blob/main/examples/custom_backend/hello_world/README.md) or [Triton Server README](https://github.com/ai-dynamo/dynamo/blob/main/examples/backends/tritonserver/README.md) for those workflows.

Run local commands from the repository root. Review model and GPU requirements in the files; replace Kubernetes image, secret, storage, and hardware settings before applying.
