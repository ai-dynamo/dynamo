<div className="dynamo-example-variant" data-example-variant="local-vllm-agg-omni-cosmos3-video-sh">

**Prerequisites:** [Cosmos3 README](https://github.com/ai-dynamo/dynamo/blob/main/examples/backends/vllm/omni/cosmos3/README.md)

**Experimental.** Requires vLLM `0.31.0`, vLLM-Omni `0.31.0rc1`, and the pinned Cosmos3 Nano
checkpoint. Qualified on one GH200 GPU with `--no-guardrails` and 33-frame, 24 fps, 1280×720
requests; these are short clips, not Cosmos's native 189-frame default. The wrapper starts the
shared launcher in video mode.

```bash
(cd examples/backends/vllm && bash launch/agg_omni_cosmos3_video.sh --no-guardrails)
```

<div className="dynamo-example-variant" data-example-variant="local-vllm-agg-omni-cosmos3-i2v-sh">

**Prerequisites:** [Cosmos3 README](https://github.com/ai-dynamo/dynamo/blob/main/examples/backends/vllm/omni/cosmos3/README.md#animate-a-reference-image)

**Experimental.** Starts the same Cosmos3 Nano video worker as `agg_omni_cosmos3_video.sh`; a
request's `input_reference` selects image-to-video. Send a client-local image as a data URI:
worker-local paths and `file://` URLs are rejected. Qualified on one GH200 GPU with
`--no-guardrails`.

```bash
(cd examples/backends/vllm && bash launch/agg_omni_cosmos3_i2v.sh --no-guardrails)
```
