The Kubernetes manifests were functionally validated on September 10, 2026 with one H100 GPU and
Dynamo 1.4.2 serving images and operator; these are correctness checks, not performance benchmarks.
Use matching 1.4.2 runtime images, and request `response_format: "b64_json"` because the
`file:///tmp/dynamo_media` storage in these examples is pod-local. See
[Text-to-Image](../../use-cases/diffusion/workflows/text-to-image.md) for requests.
