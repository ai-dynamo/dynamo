Generate speech with `Qwen/Qwen3-TTS-12Hz-1.7B-CustomVoice`. See
[Text-to-Audio](../../use-cases/diffusion/workflows/text-to-audio.md) for requests, or
[Audio and Realtime Serving](audio.mdx) for transcription and speech-to-speech.

<Warning>
**Experimental.** Both Kubernetes configurations were validated on September 18, 2026 with one H100
GPU and the existing Dynamo 1.4.2 operator, but different matched nightly serving-image pairs.
Keep each frontend/worker pair together and set `runtimeVersionOverride` to the serving images’
Dynamo version, not the operator version. Stock 1.4.2 serving images returned only an initial silent
chunk; neither these results nor a newer nightly imply general mixed-version compatibility.

Prepare `hf-token-secret` with `HF_TOKEN`, review the model’s remote code before using
`--trust-remote-code`, and adapt storage and GPU placement before deployment. The tests checked
non-silent waveform delivery and WAV framing, not listening quality or performance.
For `response_format: "wav"` with `data_source: "b64_json"`, save the raw response bytes as a WAV;
the response is not a JSON/base64 envelope.
</Warning>
