## Run Dynamo Locally

<Steps>
  <Step title="Choose and install a build">
    {/* BEGIN:install-selector — dev-only interactive selector; release snapshots replace this block with static, version-pinned commands */}
    <InstallSelector />
    {/* END:install-selector */}

    <Warning>
    **Hugging Face token required for gated models.** Llama, Kimi, Qwen-VL, and other gated models require `HF_TOKEN` in your environment and accepting the model card's license on huggingface.co. Set `export HF_TOKEN=hf_…` before launching.
    </Warning>

    The remaining steps run inside the selected container. If you installed an NVIDIA wheel instead, run the same `python3 -m dynamo.*` commands in your Python environment. See [Local Installation](../installation/install-dynamo.mdx) for host prerequisites and virtual environment setup.

    For published NVIDIA container versions and tags, see [Release Artifacts](../../reference/general/release-artifacts.mdx).
  </Step>

  <Step title="Start the frontend">
    Start the OpenAI-compatible frontend on port 8000:

    ```bash
    python3 -m dynamo.frontend --discovery-backend file
    ```

    <Tip>
    `--discovery-backend file` avoids needing etcd. To run the frontend and worker in the same terminal, background each command with `> logfile.log 2>&1 &`.
    </Tip>
  </Step>

  <Step title="Start a worker">
    In another terminal, select the hardware and backend you installed, then launch the worker:

    <WorkerSelector />
  </Step>

  <Step title="Verify the endpoint">
    Check that the endpoint is up:

    ```bash
    curl -sf http://localhost:8000/health && echo OK
    ```

    If you see `OK`, send a chat completion:

    <CodeBlocks>
    ```bash title="Request"
    curl localhost:8000/v1/chat/completions \
      -H "Content-Type: application/json" \
      -d '{"model": "Qwen/Qwen3-0.6B",
           "messages": [{"role": "user", "content": "Hello!"}],
           "max_tokens": 50}'
    ```

    ```json title="Response"
    {
      "id": "chatcmpl-...",
      "model": "Qwen/Qwen3-0.6B",
      "choices": [{
        "index": 0,
        "message": {"role": "assistant", "content": "Hello! How can I help you today?"},
        "finish_reason": "stop"
      }],
      "usage": {"prompt_tokens": 9, "completion_tokens": 10, "total_tokens": 19}
    }
    ```
    </CodeBlocks>

    <Info>
    Connection refused? The frontend takes a few seconds to start — retry. For production liveness and readiness probes, see [Health Check Reference](../../reference/observability/health-checks.mdx).
    </Info>
  </Step>
</Steps>
