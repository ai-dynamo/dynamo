NVIDIA Dynamo 是一个开源分布式推理平台。你可以通过贡献代码和文档、报告 Bug、提交设计提案、审阅变更或帮助社区来参与项目。

## 选择贡献路径

| 目标 | 从这里开始 |
| --- | --- |
| 完成第一次代码贡献 | [入门指南（英文）](contributing/getting-started.mdx) |
| 了解何时创建 Issue 以及如何提交 Pull Request | [贡献流程（英文）](contributing/contribution-flow.mdx) |
| 准备代码、测试和提交消息 | [代码质量（英文）](contributing/code-quality.md) |

错别字修复和范围明确的文档改进等小型变更通常可以直接提交 Pull Request。对于新功能、大范围重构或架构变更，请先与维护者讨论，再投入实现工作。

## 贡献方式

- [报告 Bug](https://github.com/ai-dynamo/dynamo/issues/new?template=bug_report.yml)，并提供复现步骤、预期行为、实际行为和相关环境信息。
- 在开始实现前[提出功能请求](https://github.com/ai-dynamo/dynamo/issues/new?template=feature_request.yml)。
- 浏览 [Good First Issue](https://github.com/ai-dynamo/dynamo/labels/good-first-issue) 和 [Help Wanted](https://github.com/ai-dynamo/dynamo/labels/help-wanted) Issue。
- 改进说明、示例、教程和 API 文档。
- 审阅 Pull Request，或在社区频道中回答问题。
- 对于公共 API 或架构变更，请先创建 [Dynamo Enhancement Proposal (DEP)](https://github.com/ai-dynamo/enhancements)。
