# Backend-neutral Sweeper example

This example injects a deterministic replay runner and does not import Dynamo or another application
framework.

```bash
python aisimulate/examples/sweeper/run_sweep.py \
  --config aisimulate/examples/sweeper/sweep.yaml
```
