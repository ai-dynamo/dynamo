Dynamo launch environment variables

Environment variables read at process start by the Dynamo frontend and the vLLM, TensorRT-LLM, and SGLang workers. Every variable is read by the process that hosts it, so it must be set on that process. Variables backed by a CLI flag are overridden by the flag when both are given. The few Dynamo flags with no environment variable are listed too, marked CLI only. Every entry also carries a performance-impact tag — whether changing it can move a performance number — which starts at unexamined until the setting has been reviewed. Click a name to copy it.
