# mock-mistral-tekken

A Mistral-native model folder (`params.json` + `tekken.json`, no `config.json`) for model-card tests. `tekken.json` is the v15 mock from dynamo-tokenizers' `tests/data/sample-models/mock-tekken`: the first 1,000 entries of mistral-common's public `tekken_240911.json` vocabulary, the standard special tokens, and a `reasoning_effort` settings builder.
