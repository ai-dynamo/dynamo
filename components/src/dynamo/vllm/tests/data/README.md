# Generated prefix-cache read wire contract

`prefix_cache_read_contract.json` is generated by the Rust test `frontend_prefix_cache_read_wire_contract` in `lib/llm/src/kv_router/routing_host/tests.rs`. Do not edit the JSON by hand. It contains actual serialized `PreprocessedRequest` values after the frontend normalizes and gates the cache-read decision.

The Rust test always compares its generated requests with this fixture. The Python worker tests consume the same committed fixture, so ordinary CI checks both sides of the Rust-to-Python wire mapping. `normalized` distinguishes an explicit typed decision from an ordinary request that preserves the engine default. `expected_skip` uses the worker test's default of `false` for those ordinary requests.

Regenerate from the repository root after changing the Rust producer or request wire format:

```bash
DYNAMO_CACHE_READ_CONTRACT_OUTPUT="$PWD/components/src/dynamo/vllm/tests/data/prefix_cache_read_contract.json" \
  cargo test -p dynamo-llm --lib --no-default-features frontend_prefix_cache_read_wire_contract
```

The test writes an optional export before reading the committed fixture at runtime, so this command regenerates and validates the same file. Exporting to another path still checks the committed fixture. Review the generated diff and run the Python contract test with the worker dependencies installed.
