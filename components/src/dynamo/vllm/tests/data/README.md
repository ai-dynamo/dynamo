# Generated prefix-cache read wire contract

`prefix_cache_read_contract.json` is generated by the Rust test `frontend_prefix_cache_read_wire_contract` in `lib/llm/src/kv_router/routing_host/tests.rs`. Do not edit the JSON by hand. It contains one full serialized `default_request` and ten named cases with their top-level `overrides` after frontend normalization. Shared request defaults appear once instead of being repeated in each case.

The Rust test verifies that applying each case's overrides reconstructs its complete actual wire request, then compares the corpus with this fixture. The Python tests reconstruct those same requests with a shallow top-level merge and pass them to the real worker builder. Nested objects are replaced, not recursively merged; explicit null, false, and omitted controls retain their original meanings. `expected_skip` uses the worker test's default of `false` for ordinary requests that preserve engine defaults.

Regenerate from the repository root after changing the Rust producer or request wire format:

```bash
DYNAMO_CACHE_READ_CONTRACT_OUTPUT="$PWD/components/src/dynamo/vllm/tests/data/prefix_cache_read_contract.json" \
  cargo test -p dynamo-llm --lib --no-default-features frontend_prefix_cache_read_wire_contract
```

The test writes an optional export before reading the committed fixture at runtime, so this command regenerates and validates the same file. Exporting to another path still checks the committed fixture. Review the generated diff and run the Python contract test with the worker dependencies installed.
